## 13.1 一页速览（TL;DR）

### 13.1.1 这是什么项目

**PolicyLang Meta** 是一个**领域无关的策略语言定义、可判定性编译与形式化验证元框架**（定位为「开源版通用 Zelkova」）。用户用 DSL（`.plm`）声明领域的实体本体、有界变量与声明式约束；框架在**编译期**执行：

```
Parser(P1–P2) → AST(P3) → 名称解析/拓扑排序(P4) → 类型检查 + 可判定性静态守卫(P5)
  → 有界量词展开 ground(φ)（无量词，ALG-1）→ 理论感知逻辑档位 + SMT-LIB2 生成(P6)
  → 多求解器进程级竞速（Z3/CVC5/Bitwuzla，首胜即止）→ 交叉验证
  → 反例模型 / 最小冲突核逆向翻译(P7) → 审计报告 + 退出码
```

关键立场：**不是**「又一种单一领域的策略语言」，而是**生产高可信策略语言的标准化产线**。
