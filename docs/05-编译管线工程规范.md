## 1. 管线总览

### 2.2 Span 映射

`pest::Span`（字节偏移）在 `P2` 转为带行列的 `ast::Span`。`P1` 一次性构建 `LineIndex`（每个 `\n` 后记一行首字节），`byte→(line,col)` 查询 `O(log n)`。

```rust
use pest::Span as PestSpan;
pub struct LineIndex { line_starts: Vec<usize> }
impl LineIndex {
    pub fn new(src: &str) -> Self {
        let mut ls = vec![0];
        for (i, b) in src.bytes().enumerate() { if b == b'\n' { ls.push(i + 1); } }
        Self { line_starts: ls }
    }
    pub fn locate(&self, byte: usize) -> (u32, u32) {   // 1-based 行列
        let l = match self.line_starts.binary_search(&byte) { Ok(l) => l, Err(l) => l.saturating_sub(1) };
        (l as u32 + 1, (byte - self.line_starts[l]) as u32 + 1)
    }
}
pub fn to_ast_span(s: PestSpan<'_>, idx: &LineIndex) -> crate::ast::Span {
    let (sl, sc) = idx.locate(s.start()); let (el, ec) = idx.locate(s.end());
    crate::ast::Span { start_byte: s.start(), end_byte: s.end(), start_line: sl, start_col: sc, end_line: el, end_col: ec }
}
```

### 2.3 错误恢复与 `E-PARSE-*` 诊断格式

Pest 的 `Error` 携带失败位置（`Rule` + `line_col`）；`P1` 规范化为单条 `Diagnostic`（`code` + `message` + `span` + `fixes`）：

```rust
pub fn normalize_pest_error(src: &str, e: pest::error::Error<Rule>) -> Diagnostic {
    let idx = LineIndex::new(src);
    let (line, col) = match e.line_col {                // Pos 与 Span 两种位置形
        pest::error::LineColLocation::Pos((l, c)) => (l, c),
        pest::error::LineColLocation::Span((l, c), _) => (l, c),
    };
    let byte = idx.line_starts.get(line - 1).copied().unwrap_or(0) + (col - 1);
    Diagnostic { code: "E-PARSE-SYNTAX",
        message: format!("语法错误 @ {}:{}：期望 {:?}", line, col, e.variant),
        span: crate::ast::Span { start_byte: byte, end_byte: byte, start_line: line as u32,
            start_col: col as u32, end_line: line as u32, end_col: col as u32 + 1 },
        fixes: vec!["按 04 §2 核对文法；注意保留字表（04 §2.3）".into()] }
}
```

**专用解析错误**（`P1` 后置校验产生，非 Pest 原生）：`E-PARSE-LANG-HEADER`（缺 `#lang policylang 2` 或主版本 ≠ 2，检测于 `spec_file` 首子节点）；`E-PARSE-ESCAPE`（`escape_seq` 之外的 `\` 序列，检测于 `str_char` 求解后扫描）。

### 2.4 字符串转义解码

`decode_string_literal(raw)` 去首尾引号后逐字符扫描：非 `\` 原样保留；`\` 后按 `\\ \" \n \t \r` 直接映射、`\xHH`（2 位十六进制）、`\uHHHH`（4 位十六进制）解码为 `char`，其余序列返回 `E-PARSE-ESCAPE`。仅允许 `04 §2.4` 列出的转义（`\0`、`\b`、`\f`、`\v` 均非法）。

### 3.2 排序与范围约束

```rust
#[derive(Debug, Clone, PartialEq, Eq, Hash)]
pub enum Type { Int, Real, Bool, Str, BitVec(u32), Enum(Vec<String>) }   // Str 对应 03 排序 Str

impl Type {
    pub fn ipv4() -> Type { Type::BitVec(32) }        // IPv4 / IPv6 别名在 P2 已解析（04 §4.2）
    pub fn ipv6() -> Type { Type::BitVec(128) }
    pub fn smt_sort(&self) -> String {                // Enum 编码为 Int + 成员闭包（04 §4.1）
        match self {
            Type::Int | Type::Enum(_) => "Int".into(), Type::Real => "Real".into(),
            Type::Bool => "Bool".into(), Type::Str => "String".into(),
            Type::BitVec(n) => format!("(_ BitVec {})", n),
        }
    }
}

/// 精确有理数：Real 端点与字面量必须用此类型，严禁 f64（03 §3.2.3 N-1）。
/// 与 doc 03 N-1 的冲突：上游 `RangeConstraint::Numeric { min: f64, max: f64 }` 已废弃。
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash)]
pub struct Rational { pub num: i128, pub den: i128 }
impl Rational {
    pub fn new(mut num: i128, mut den: i128) -> Option<Self> {
        if den == 0 { return None; }
        if den < 0 { num = -num; den = -den; }
        let g = gcd(num.unsigned_abs(), den as u128) as i128;
        Some(Rational { num: num / g, den: den / g })
    }
    pub fn from_int(n: i128) -> Self { Rational { num: n, den: 1 } }
    pub fn is_integer(&self) -> bool { self.den == 1 }
    pub fn to_smt_lib(&self) -> String {
        if self.den == 1 { self.num.to_string() } else { format!("(/ {} {})", self.num, self.den) }
    }
}
fn gcd(mut a: u128, mut b: u128) -> u128 { while b != 0 { let t = a % b; a = b; b = t; } a }

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum RangeConstraint {
    Numeric { min: Rational, max: Rational },   // Int/Real 的 [min,max]（Int 侧要求 den == 1）
    Length  { min: u64, max: u64 },             // String 的 [length: l..u]
}
```

```rust
    InAddrRange { expr: Expr, lo: String, hi: String }, // in_range(e,"lo","hi")（03 §3.12.3）

    Implies(Box<Formula>, Box<Formula>),
    Iff(Box<Formula>, Box<Formula>),                    // φ iff ψ（03 §3.4.3 最低优先级）
```

> **上游缺口补全清单**（P2 层）：① `Formula::Iff`（上游缺 `iff`，最低优先级无落点）；② `Formula::BoolAtom`（缺布尔原子，`§FR-2` 示例不可解析，缺陷 `B-2`）；③ `Formula::InRange`（缺区间成员，`B-4`）；④ `Formula::Unique`（缺 `unique(D, f)`，`B-1`）；⑤ `Expr::Flat { domain, index, field }` 取代上游 `Expr::Var(format!("{}_{}", prefix, field))` 的字符串拼接（`03 §3.6.2` 补全 `B-9`），保证 `scalar_symbol` **单一命名实现**；⑥ `Type::Real` 字面量与端点改用 `Rational { num: i128, den: i128 }`（上游 `f64` 与 `03` N-1 精确有理数语义冲突，已废弃）。

## 4. P3 名称解析与声明拓扑排序

### 4.1 依赖图与拓扑排序（`03 §3.3.1` D-1）

依赖图 `S → E`、`D → E`、`V → {P, I}`；拓扑排序存在环即 `E-CYCLIC-DECL`。

```rust
use std::collections::BTreeMap;
pub struct ResolvedSpec { pub entities: BTreeMap<String, EntityDecl>, pub domains: BTreeMap<String, DomainDecl>,
    pub variables: BTreeMap<String, VarDecl>, pub policies: BTreeMap<String, PolicyDecl>,
    pub invariants: BTreeMap<String, InvariantDecl>, pub requires: BTreeMap<String, RequireDecl>,
    pub waivers: BTreeMap<String, WaiverDecl>, pub decl_order: Vec<String> }   // 拓扑序（字典序入队）

pub fn resolve(spec: &Spec) -> Result<ResolvedSpec, Vec<Diagnostic>> {
    let mut errs = Vec::new();
    let mut ents = BTreeMap::new();
    for e in &spec.entities {                       // 同名重复 => E-DUP-SYMBOL
        if ents.insert(e.name.clone(), e.clone()).is_some() { errs.push(dup_symbol(&e.name, e.span)); } }
    for d in &spec.domains {                        // 未声明实体 => E-UNKNOWN-ENTITY
        if !ents.contains_key(&d.entity_type) { errs.push(unknown_entity(&d.entity_type, d.span)); } }
    let order = topo_sort(spec, &mut errs)?;        // 有环 => E-CYCLIC-DECL
    if errs.is_empty() { Ok(assemble(spec, order)) } else { Err(errs) }
}
```

### 4.2 作用域、词法遮蔽与前向引用（D-2）

| 规则 | 内容 | 违反 |
|---|---|---|
| 绑定变量作用域 | 限于其量词体 | — |
| 全局变量可见性 | 覆盖全部规则/不变量/分支，含量化体内部 | — |
| 词法遮蔽 | 绑定变量可遮蔽同名全局变量 | `W-SHADOW`（警告，非错误） |
| 跨域实例引用 | 禁止在量化体内引用另一域实例 | `E-CROSS-DOMAIN-REF` |

拓扑排序使**声明书写顺序不受约束**：`verify` 可引用后文策略，`domain` 可引用后文实体，无需前向声明。跨域字段引用在 `P3` 以「解析到两个不同域的绑定」判定并报 `E-CROSS-DOMAIN-REF`；遮蔽检测在绑定入环境时执行，写入 `warnings`（`W-SHADOW`）。

### 5.2 `LogicProfile` 完整实现与 `uses_*` / `covers_*`

`check_expr` 逐节点**正确赋值** `uses_*`（上游 v2.0 从未赋值，`deduce_smt_logic` 恒得 `"ALL"`）。

```rust
use crate::ast::*;

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Logic { QfLia, QfLra, QfLira, QfBv, QfBvlia, QfSlia, Combined(String) }  // Combined: TH-3a/DD-3.2
impl Logic {
    pub fn as_str(&self) -> &str { match self {
        Logic::QfLia => "QF_LIA", Logic::QfLra => "QF_LRA", Logic::QfLira => "QF_LIRA",
        Logic::QfBv => "QF_BV", Logic::QfBvlia => "QF_BVLIA", Logic::QfSlia => "QF_SLIA",
        Logic::Combined(s) => s.as_str() } }
}

#[derive(Debug, Clone, Default)]
pub struct LogicProfile {
    pub uses_int: bool, pub uses_real: bool, pub uses_bv: bool,
    pub uses_string: bool, pub uses_reglan: bool, pub uses_enum: bool,
    pub has_nonlinear_violation: bool,
    pub violations: Vec<Violation>,
    pub lin_div_ctx: bool,       // 由父比较节点回填的 LinDiv(a,b,c) 上下文
}
#[derive(Debug, Clone)] pub struct Violation { pub kind: &'static str, pub detail: String, pub span: Span }

impl LogicProfile {
    pub fn check_expr(&mut self, e: &Expr) {
        match e {
            Expr::IntLit(_) => self.uses_int = true,
            Expr::RealLit(_) => self.uses_real = true,
            Expr::StrLit(_) => self.uses_string = true,
            Expr::Var(_) | Expr::Flat { .. } | Expr::FieldAccess { .. } => { /* 排序由 Γ 决定 */ }
            Expr::StrLen(inner) => { self.uses_string = true; self.uses_int = true; self.check_expr(inner); }
            Expr::Cast { kind, from } => {
                match kind { CastKind::ToReal => self.uses_real = true,
                    CastKind::Int2Bv(_) => { self.uses_bv = true; self.uses_int = true; }
                    CastKind::Bv2Int => { /* 已在 W8 拒绝 */ } }
                self.check_expr(from); }
            Expr::BvOp { left, right, .. } => { self.uses_bv = true; self.check_expr(left);
                if let Some(r) = right { self.check_expr(r); } }
            Expr::Unary { operand, .. } => self.check_expr(operand),
            Expr::Binary { op, left, right } => {
                match op { ArithOp::Div => self.uses_real = true, _ => self.uses_int = true }
                self.guard_nonlinear(*op, left, right);      // §5.5
                self.check_expr(left); self.check_expr(right); }
        }
    }

        self.uses_reglan |= other.uses_reglan;
        self.uses_enum   |= other.uses_enum;

    }

    pub fn covers_real(&self)   -> bool { self.uses_real }
    pub fn covers_bv(&self)     -> bool { self.uses_bv }
```

### 5.4 非线性守卫的精确准则（修正上游 `C-5` 漏洞）

```
拒绝 ⟺ op ∈ {Mul} ∧ ¬is_const(l) ∧ ¬is_const(r)          —— 两侧非常量
     ∨ op ∈ {IDiv, Mod} ∧ ¬is_const(r)                    —— 除数非常量
     ∨ op ∈ {Div} ∧ ¬is_const(r) ∧ ¬LinDiv                —— 除数非常量且 TH-4 线性化不成立
is_const(e) ≜ e 中不含 Var / FieldAccess / Flat          LinDiv(a,b,c) ≜ isConst(b) ∨ isConst(c)（03 §3.11.3）
```

上游守卫写作 `!left.is_constant() && !right.is_constant()`，**漏掉** `2 / x`、`2 div x`、`2 mod x`（左侧常量、右侧变量）这一真正非线性且不可判定的构造。

```rust
impl LogicProfile {
    fn guard_nonlinear(&mut self, op: ArithOp, l: &Expr, r: &Expr) {
        let bad = match op {
            ArithOp::Mul => !is_const(l) && !is_const(r),
            ArithOp::IDiv | ArithOp::Mod => !is_const(r),
            ArithOp::Div => !is_const(r) && !self.lin_div_ctx,   // LinDiv 由父比较节点回填
            _ => false };
        if bad { self.has_nonlinear_violation = true;
            self.violations.push(Violation { kind: "E-NONLINEAR",
                detail: format!("非线性算术：{:?} 存在非常量操作数", op), span: Span::default() }); }
    }
}
pub fn is_const(e: &Expr) -> bool {
    match e {
        Expr::Var(_) | Expr::FieldAccess { .. } | Expr::Flat { .. } => false,
        Expr::IntLit(_) | Expr::RealLit(_) | Expr::BoolLit(_) | Expr::StrLit(_) => true,
        Expr::Unary { operand, .. } => is_const(operand),
        Expr::Binary { left, right, .. } => is_const(left) && is_const(right),
        Expr::StrLen(x) | Expr::Cast { from: x, .. } => is_const(x),
        Expr::BvOp { left, right, .. } => is_const(left) && right.as_deref().map_or(true, is_const),
    }
}
```

```rust
fn occurring(body: &Formula, vars: &[String]) -> usize { vars.iter().filter(|v| occurs_in(body, v)).count() }
fn occurs_in(f: &Formula, v: &str) -> bool {
    match f {
        Formula::Predicate { left, right, .. } => occurs_expr(left, v) || occurs_expr(right, v),
        Formula::BoolAtom(e) | Formula::InRange { value: e, .. } | Formula::MatchesAll { expr: e, .. }
        | Formula::InCidr { expr: e, .. } | Formula::InAddrRange { expr: e, .. } => occurs_expr(e, v),
        Formula::And(xs) | Formula::Or(xs) => xs.iter().any(|x| occurs_in(x, v)),
        Formula::Not(x) => occurs_in(x, v),
        Formula::Implies(a, b) | Formula::Iff(a, b) => occurs_in(a, v) || occurs_in(b, v),
        Formula::Forall { body, .. } | Formula::Exists { body, .. } => occurs_in(body, v),
        Formula::Unique { .. } | Formula::True | Formula::False => false,
    }
}
fn occurs_expr(e: &Expr, v: &str) -> bool {
    match e {
        Expr::FieldAccess { instance, .. } => instance == v,
        Expr::Var(_) | Expr::Flat { .. } | Expr::IntLit(_) | Expr::RealLit(_) | Expr::BoolLit(_) | Expr::StrLit(_) => false,
        Expr::Unary { operand, .. } => occurs_expr(operand, v),
        Expr::Binary { left, right, .. } => occurs_expr(left, v) || occurs_expr(right, v),
        Expr::StrLen(x) | Expr::Cast { from: x, .. } => occurs_expr(x, v),
        Expr::BvOp { left, right, .. } => occurs_expr(left, v) || right.as_deref().map_or(false, |r| occurs_expr(r, v)),
    }
}
fn injective_count(n: u64, k: u32) -> u64 {                 // N·(N−1)···(N−k+1)
    let mut acc = 1u64;
    for i in 0..k as u64 { if i >= n { return 0; } acc = acc.saturating_mul(n - i); } acc
}
pub fn grounding_size(f: &Formula, dt: &DomainTable) -> u64 {
    match f {
        Formula::And(xs) | Formula::Or(xs) => xs.iter().map(|x| grounding_size(x, dt)).fold(0u64, u64::saturating_add),
        Formula::Not(x) => grounding_size(x, dt),
        Formula::Implies(a, b) | Formula::Iff(a, b) => grounding_size(a, dt).saturating_add(grounding_size(b, dt)),
        Formula::Forall { vars, domain, distinct, body } | Formula::Exists { vars, domain, distinct, body } => {
            let n = dt.size_of(domain); let k = occurring(body, vars) as u32;
            let factor = if k == 0 { 1 } else if *distinct { injective_count(n, k) } else { n.saturating_pow(k) };
            factor.saturating_mul(grounding_size(body, dt)) }
        _ => 1,                                             // 叶子原子 A(atom) = 1
    }
}
```

### 6.2 绑定环境与展开器

```rust
use crate::symbol::scalar_symbol;
use std::collections::{BTreeMap, HashSet};
type BindEnv = BTreeMap<String, (String, usize)>;           // 绑定变量 → (域名, 索引)
pub struct DomainTable { pub sizes: BTreeMap<String, u64> }
impl DomainTable { pub fn size_of(&self, d: &str) -> usize { *self.sizes.get(d).unwrap_or(&1) as usize } }

pub fn ground(f: &Formula, env: &BindEnv, dt: &DomainTable) -> Formula {
    match f {
        Formula::Forall { vars, domain, distinct, body } => quantify(true, vars, domain, *distinct, body, env, dt),
        Formula::Exists { vars, domain, distinct, body } => quantify(false, vars, domain, *distinct, body, env, dt),
        Formula::And(xs) => Formula::And(xs.iter().map(|x| ground(x, env, dt)).collect()),
        Formula::Or(xs)  => Formula::Or (xs.iter().map(|x| ground(x, env, dt)).collect()),
        Formula::Not(x)  => Formula::Not(Box::new(ground(x, env, dt))),
        Formula::Implies(a, b) => Formula::Implies(Box::new(ground(a, env, dt)), Box::new(ground(b, env, dt))),
        Formula::Iff(a, b) => Formula::Iff(Box::new(ground(a, env, dt)), Box::new(ground(b, env, dt))),
        Formula::Predicate { left, op, right } =>
            Formula::Predicate { left: ground_expr(left, env), op: *op, right: ground_expr(right, env) },
        Formula::BoolAtom(e) => Formula::BoolAtom(ground_expr(e, env)),
        Formula::InRange { value, lo, hi } => Formula::InRange {
            value: ground_expr(value, env), lo: ground_expr(lo, env), hi: ground_expr(hi, env) },
        Formula::MatchesAll { expr, patterns } => Formula::MatchesAll { expr: ground_expr(expr, env), patterns: patterns.clone() },
        Formula::InCidr { expr, cidr } => Formula::InCidr { expr: ground_expr(expr, env), cidr: cidr.clone() },
        Formula::InAddrRange { expr, lo, hi } => Formula::InAddrRange {
            expr: ground_expr(expr, env), lo: lo.clone(), hi: hi.clone() },
        Formula::Unique { domain, field } => Formula::Unique { domain: domain.clone(), field: field.clone() },
        other => other.clone(),
    }
}

fn quantify(is_forall: bool, vars: &[String], domain: &str, distinct: bool,
            body: &Formula, env: &BindEnv, dt: &DomainTable) -> Formula {
    let n = dt.size_of(domain);
    let occurring: Vec<usize> = vars.iter().enumerate()     // 部分出现剪枝（ALG-1-P）
        .filter(|(_, v)| occurs_in(body, v)).map(|(i, _)| i).collect();
    if occurring.is_empty() { return ground(body, env, dt); }   // 死变量剪枝（k' = 0）
    let tuples = if distinct { injective_indices(n, occurring.len()) } else { lex_indices(n, occurring.len()) };
    let mut acc: Vec<Formula> = Vec::with_capacity(tuples.len());
    for tup in tuples {                                     // 字典序枚举（DET-1），保序（DET-2）
        let mut e = env.clone();
        for (slot, &vi) in occurring.iter().enumerate() { e.insert(vars[vi].clone(), (domain.to_string(), tup[slot])); }
        acc.push(ground(body, &e, dt));
    }
    let combined = if is_forall { Formula::And(acc) } else { Formula::Or(acc) };
    dedup_alpha(fold_constants(combined))                   // FOLD-1 常量折叠 + FOLD-2 α-去重
}

fn ground_expr(e: &Expr, env: &BindEnv) -> Expr {            // 项层重命名（03 §3.6.2）
    match e {
        Expr::FieldAccess { instance, field } => {
            let (dom, idx) = env.get(instance).expect("P4 已保证绑定变量存在（W5）");
            Expr::Flat { domain: dom.clone(), index: *idx, field: field.clone() } }
        Expr::Binary { op, left, right } => Expr::Binary {
            op: *op, left: Box::new(ground_expr(left, env)), right: Box::new(ground_expr(right, env)) },
        Expr::Unary { op, operand } => Expr::Unary { op: *op, operand: Box::new(ground_expr(operand, env)) },
        Expr::StrLen(x) => Expr::StrLen(Box::new(ground_expr(x, env))),
        Expr::Cast { kind, from } => Expr::Cast { kind: *kind, from: Box::new(ground_expr(from, env)) },
        Expr::BvOp { op, left, right } => Expr::BvOp { op: *op, left: Box::new(ground_expr(left, env)),
            right: right.as_ref().map(|r| Box::new(ground_expr(r, env))) },
        other => other.clone(),
    }
}
```

### 6.3 枚举顺序（`DET-1`）与单射枚举

```rust
pub fn lex_indices(n: usize, k: usize) -> Vec<Vec<usize>> {   // Fin(n)^k 字典序（末位最快）
    let mut out = Vec::new();
    if k == 0 { out.push(Vec::new()); return out; }
    let mut cur = vec![0usize; k];
    loop { out.push(cur.clone());
        let mut i = k;
        loop { if i == 0 { return out; } i -= 1; cur[i] += 1;
            if cur[i] < n { break; } cur[i] = 0; } }
}
pub fn injective_indices(n: usize, k: usize) -> Vec<Vec<usize>> {   // Inj(idx(D), k)（03 §3.5.2）
    lex_indices(n, k).into_iter()
        .filter(|t| { let mut seen = HashSet::new(); t.iter().all(|&x| seen.insert(x)) }).collect()
}
```

### 6.4 常量折叠、α-等价去重与 CSE

```rust
/// FOLD-1：and(…, true, …) 消去 true；出现 false 则整体化为 false（`:named` 影子记录由 P6 保留）。
pub fn fold_constants(f: Formula) -> Formula {
    match f {
        Formula::And(xs) => { let mut o = Vec::new();
            for x in xs { match fold_constants(x) { Formula::False => return Formula::False, Formula::True => {}, y => o.push(y) } }
            match o.len() { 0 => Formula::True, 1 => o.pop().unwrap(), _ => Formula::And(o) } }
        Formula::Or(xs) => { let mut o = Vec::new();
            for x in xs { match fold_constants(x) { Formula::True => return Formula::True, Formula::False => {}, y => o.push(y) } }
            match o.len() { 0 => Formula::False, 1 => o.pop().unwrap(), _ => Formula::Or(o) } }
        Formula::Not(x) => match fold_constants(*x) {
            Formula::True => Formula::False, Formula::False => Formula::True, y => Formula::Not(Box::new(y)) },
        other => other,
    }
}
/// FOLD-2：相邻完全同构子式去重（α-等价），把对称项由 N² 降到 N(N+1)/2（保序）。
pub fn dedup_alpha(f: Formula) -> Formula {
    match f { Formula::And(xs) => Formula::And(dedup_ordered(xs)),
              Formula::Or(xs) => Formula::Or(dedup_ordered(xs)), other => other }
}
fn dedup_ordered(xs: Vec<Formula>) -> Vec<Formula> {
    let mut seen = HashSet::new(); xs.into_iter().filter(|x| seen.insert(format!("{:?}", x))).collect()
}
/// CSE-1：公共子式（尤其 str.in_re）提为 (let ((t …)) …)，控制文本规模。
pub struct CseTable { counter: usize, entries: std::collections::HashMap<String, String> }
impl CseTable {
    pub fn new() -> Self { Self { counter: 0, entries: Default::default() } }
    pub fn intern(&mut self, key: String) -> String {
        if let Some(n) = self.entries.get(&key) { return n.clone(); }
        let name = format!("t{}", self.counter); self.counter += 1; self.entries.insert(key, name.clone()); name
    }
}
```

| 实数常量 | `(/ num den)` 或 `to_real` | 不得用浮点（N-1） |
| 负整数 | `(- 5)` | `(- 5)` 与字面量 `-5` 语义不同 |
| 枚举成员 | `(declare-const E_<name> Int)` + 闭包 `(or (= x m₁) …)` + 两两 `(distinct m₁ …)` | — |

```rust
pub fn emit_literal_bv(v: u128, w: u32) -> String { format!("(_ bv{} {})", v, w) }
pub fn emit_literal_int(i: i128) -> String { if i < 0 { format!("(- {})", -i) } else { i.to_string() } }
pub fn emit_literal_real(r: &Rational) -> String { r.to_smt_lib() }
```

### 7.6 文本规模控制与惰性拼接

- **分块发射**：按「声明块 / 边界块 / 断言块 / 指令块」分块，每块独立 `String`，最终一次性拼接。
- **惰性拼接**：以 `Vec<String>` 收集片段再 `join`，避免高频 `push_str` 触发的重复扩容（§10）。
- **CSE**：`str.in_re` 与重复子式经 `CseTable` 提为 `(let ((t0 …)) …)`（§6.4）。

## 8. P7 诊断逆向翻译

### 8.1 S-Expr 解析器

```rust
#[derive(Debug, Clone, PartialEq)]
pub enum SExpr { Atom(String), List(Vec<SExpr>) }
pub fn parse_sexprs(input: &str) -> Result<Vec<SExpr>, DiagError> {
    let mut it = input.chars().peekable();
    let mut out = Vec::new();
    loop { skip_ws_comments(&mut it); if it.peek().is_none() { return Ok(out); } out.push(parse_one(&mut it)?); }
}
fn parse_one(it: &mut std::iter::Peekable<std::str::Chars<'_>>) -> Result<SExpr, DiagError> {
    skip_ws_comments(it);
    match it.next() {
        Some('(') => { let mut items = Vec::new();
            loop { skip_ws_comments(it);
                match it.peek() { Some(')') => { it.next(); return Ok(SExpr::List(items)); }
                    None => return Err(DiagError::UnbalancedParen), _ => items.push(parse_one(it)?) } } }
        Some('|') => Ok(SExpr::Atom(read_quoted(it, '|')?)),        // SMT-LIB |symbol|
        Some('"') => Ok(SExpr::Atom(read_quoted(it, '"')?)),
        Some(c) => { let mut s = String::from(c);
            while let Some(&c) = it.peek() { if c.is_whitespace() || c == '(' || c == ')' { break; } s.push(c); it.next(); }
            Ok(SExpr::Atom(s)) }
        None => Err(DiagError::UnexpectedEof),
    }
}
```

## 10. 编译性能工程

| 目标 | 设计 | 依据 |
|---|---|---|
| 检查阶段 1000 行 DSL < 200ms（`NFR-2a`） | P1–P4 全程 `O(|φ|)`；`G` 静态计算不展开；正则/CIDR 校验线性扫描 | `03 §3.10.4` |
